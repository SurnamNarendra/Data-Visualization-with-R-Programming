Lecture 5 — Hypothesis Testing

Hypothesis testing is a statistical procedure used to make decisions or inferences about population parameters based on sample data. It allows researchers to evaluate claims, compare groups, and determine the likelihood of observed effects being due to chance.

1. Null and Alternative Hypotheses

In hypothesis testing, we formulate:

  • Null Hypothesis (H₀): A statement that there is no effect or difference. It represents the status quo.
  • Alternative Hypothesis (H₁ or Ha): A statement that there is an effect or difference.
Examples:
  • H₀: Mean fasting glucose level in diabetic patients = 120 mg/dL; H₁: Mean fasting glucose ≠ 120 mg/dL.
  • H₀: A new drug has no effect on enzyme activity; H₁: The drug alters enzyme activity.
  • H₀: Mean blood pressure is the same in males and females; H₁: Mean blood pressure differs between sexes.

2. Types of Errors

  • Type I Error (α): Rejecting H₀ when it is true. Example: Concluding a drug affects cholesterol when it actually does not.
  • Type II Error (β): Failing to reject H₀ when it is false. Example: Concluding a drug has no effect on enzyme activity when it actually does.

3. Significance Level and P-value

  • Significance Level (α): Predefined probability threshold for rejecting H₀ (commonly 0.05 or 0.01).
  • P-value: Probability of obtaining results as extreme as the observed data if H₀ is true. - If P ≤ α → Reject H₀ - If P > α → Fail to reject H₀
Examples:
  • P = 0.03 for a test comparing mean glucose levels → Reject H₀ at α = 0.05.
  • P = 0.12 for difference in hemoglobin levels → Fail to reject H₀ at α = 0.05.

4. Test Statistics

Test statistics quantify how far the sample statistic is from the population parameter under H₀.

  • Z-test (for large samples, known σ):

    Z = (X̄ - μ₀) / (σ / √n)

  • t-test (for small samples, unknown σ):

    t = (X̄ - μ₀) / (s / √n)

  • Chi-square test (for categorical data):

    χ² = Σ (O - E)² / E

    O = observed frequency, E = expected frequency
  • ANOVA (Analysis of Variance): Compares means across multiple groups using F-statistic.
Examples:
  • One-sample t-test: Test if mean blood glucose differs from 120 mg/dL in a sample of 25 patients.
  • Two-sample t-test: Compare mean cholesterol levels between males and females.
  • Chi-square test: Compare observed vs expected blood type frequencies in a population.
  • ANOVA: Compare mean enzyme activity across three different treatment groups.

5. Steps in Hypothesis Testing

  1. Formulate H₀ and H₁.
  2. Choose significance level α.
  3. Select the appropriate test and compute the test statistic.
  4. Calculate P-value or compare test statistic with critical value.
  5. Make a decision: Reject or fail to reject H₀.
  6. Interpret results in context.

6. Summary

  • Hypothesis testing evaluates claims about population parameters using sample data.
  • Null and alternative hypotheses provide the framework for testing.
  • Type I and Type II errors indicate the risks of incorrect decisions.
  • Significance level and P-values guide decision-making.
  • Test statistics depend on data type, sample size, and variance information.
  • Applications in biological and medical research include comparing treatments, evaluating drug effects, and analyzing physiological data.
