Data Import and Cleaning

Aim

To import biological data and handle missing or outlier values in R.

Algorithm / Procedure

  • Use read.csv() to load dataset.
  • Apply na.omit(), is.na(), and summary() for cleaning.

Input / Output

Input:
> data <- read.csv('bio_data.csv')
> summary(data)
Output:
Summary of dataset

Result

Imported dataset and performed basic data cleaning.
