Lab 5: Correlation Analysis Using R

Explore Relationships Between Variables Using Correlation Coefficients and Visualization

Aim

To calculate, interpret, and visualize correlation coefficients between variables using R, and understand the strength and direction of relationships.

Procedure

  1. Load a dataset and inspect its structure.
  2. Compute correlation coefficients using cor().
  3. Visualize correlations with scatter plots and heatmaps.
  4. Interpret correlation strength and direction.
  5. Identify significant correlations for analysis.

Algorithm

  1. Start RStudio and set working directory.
  2. Load the dataset using read.csv() or use built-in datasets like mtcars.
  3. Inspect dataset with str() and summary().
  4. Calculate correlation matrix: cor(data).
  5. Visualize correlation using plot() or libraries like corrplot.
  6. Interpret the correlation coefficients and identify relationships.

Source Code

# Load dataset
data <- read.csv("your_dataset.csv")

# Inspect dataset
str(data)
summary(data)

# Compute correlation matrix
cor_matrix <- cor(data)
cor_matrix

# Visualize scatter plot
plot(data$X1, data$X2, main="Scatter Plot of X1 vs X2", xlab="X1", ylab="X2")

# Using corrplot for heatmap
library(corrplot)
corrplot(cor_matrix, method="color", addCoef.col="black")

Sample Output

# Correlation Matrix
X1 X2 Y
X1 1.0000 0.7563 0.6541
X2 0.7563 1.0000 0.8124
Y 0.6541 0.8124 1.0000

Interpretation

  • Correlation Coefficient (r): Ranges from -1 to 1. Positive values indicate positive association, negative values indicate negative association.
  • Strength: |r| > 0.7 is strong, 0.3–0.7 is moderate, < 0.3 is weak.
  • Direction: Positive r → variables increase together, Negative r → one increases while other decreases.
  • Use visualizations to confirm linear relationships and detect patterns.

Conclusion

In this lab, you learned how to compute and interpret correlation coefficients in R. You visualized relationships using scatter plots and correlation heatmaps, enabling better understanding of variable associations. Correlation analysis is essential before applying regression or other predictive models.
