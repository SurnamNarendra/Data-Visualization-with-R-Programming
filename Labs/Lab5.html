Lab 5: Correlation Analysis Using R

Aim

To compute correlation between variables in a dataset, interpret correlation results, visualize the relationship and perform correlation tests using R programming.

Objectives

  1. Load a dataset and inspect the variables.
  2. Compute Pearson correlation coefficient using cor().
  3. Perform correlation hypothesis test using cor.test().
  4. Visualize correlations with scatter plots and correlogram.
  5. Interpret correlation coefficients and statistical significance.

Algorithm

  1. Start RStudio and set working directory.
  2. Load the dataset into R using read.csv().
  3. Check structure and summary of data.
  4. Compute correlation coefficient using cor().
  5. Perform correlation test using cor.test().
  6. Visualize the correlation using scatter plot and correlation matrix.
  7. Interpret the results.

R Code – Correlation Analysis

# Load dataset
data <- read.csv("your_dataset.csv")

# Display structure and summary
str(data)
summary(data)

# Compute Pearson correlation between two numeric variables
corr_value <- cor(data$X, data$Y, method="pearson")
print(corr_value)

# Perform correlation test
corr_test <- cor.test(data$X, data$Y, method="pearson")
print(corr_test)

# Scatter plot with correlation coefficient (optional)
plot(data$X, data$Y, main="Scatter Plot of X vs Y", xlab="X", ylab="Y")
abline(lm(data$Y ~ data$X), col="red")

# Correlation matrix for multiple numeric columns
num_data <- data[, sapply(data, is.numeric)]
corr_matrix <- cor(num_data, method="pearson")
print(round(corr_matrix, 2))

Interpretation

  • A correlation coefficient close to +1 indicates strong positive linear relationship.
  • A coefficient close to –1 indicates strong negative linear relationship.
  • If the p‑value < 0.05, the correlation is statistically significant at 5% level.
