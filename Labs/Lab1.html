Lab 1: Introduction to R Environment and Basic Operations

Learn variables, loops, functions, vectors, sequences, conditions, and simple data handling in R.

Aim

To understand the R working environment, perform basic operations, explore vectors, use loops, implement conditions, create user-defined functions, and work with basic data structures in RStudio.

Algorithm

  1. Open RStudio and set the working directory.
  2. Define numeric variables and perform arithmetic operations.
  3. Create vectors and sequences using R functions.
  4. Use conditional statements such as if and if-else.
  5. Use for and while loops for iteration.
  6. Create a user-defined function and call it with arguments.
  7. Create a simple data frame and access its elements.
  8. Execute the script and observe outputs in the console.

Source Code

# Lab 1: Introduction to R Environment and Basic Operations

# 1. Define Variables
a <- 10
b <- 5

# Arithmetic operations
sum_result <- a + b
diff_result <- a - b
prod_result <- a * b
div_result <- a / b

cat("Sum:", sum_result, "\n")
cat("Difference:", diff_result, "\n")
cat("Product:", prod_result, "\n")
cat("Division:", div_result, "\n\n")

# 2. Working with Vectors
vec <- c(10, 20, 30, 40, 50)
cat("Vector Elements:", vec, "\n")
cat("Vector Mean:", mean(vec), "\n")
cat("Vector Length:", length(vec), "\n\n")

# 3. Sequences in R
seq1 <- seq(1, 10, by = 2)
cat("Sequence (1 to 10, step 2):", seq1, "\n\n")

# 4. Conditional Statements
num <- 12
if (num %% 2 == 0) {
  cat(num, "is Even\n\n")
} else {
  cat(num, "is Odd\n\n")
}

# 5. For Loop
cat("For Loop Result:\n")
for (i in 1:5) {
  cat("Iteration:", i, "\n")
}

cat("\n")

# 6. While Loop
cat("While Loop Result:\n")
x <- 1
while (x <= 5) {
  cat("x =", x, "\n")
  x <- x + 1
}

cat("\n")

# 7. User-Defined Function
add_numbers <- function(x, y) {
  result <- x + y
  return(result)
}

cat("Function Output: add_numbers(12, 8) =", add_numbers(12, 8), "\n\n")

# 8. Simple Data Frame
students <- data.frame(
  Name = c("Ravi", "Teja", "Asha"),
  Marks = c(85, 92, 78)
)

cat("Student Data Frame:\n")
print(students)

cat("\nMarks of Teja =", students$Marks[2], "\n")
