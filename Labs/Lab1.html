Lab 1: Introduction to R Environment and Basic Operations

Practice using RStudio, define variables, loops, and user-defined functions for simple data operations.

Aim

To get familiar with the R environment and perform basic operations such as defining variables, using loops, and creating user-defined functions in RStudio.

Algorithm

  1. Open RStudio and set the working directory.
  2. Define variables and perform basic arithmetic operations.
  3. Use control structures such as for and while loops.
  4. Create a user-defined function to perform a specific task.
  5. Run the script and verify the outputs in the R console.

Source Code

# Lab 1: Introduction to R Environment and Basic Operations

# 1. Define variables
a <- 10
b <- 5

# 2. Perform arithmetic operations
sum_result <- a + b
diff_result <- a - b
prod_result <- a * b
div_result <- a / b

cat("Sum:", sum_result, "\n")
cat("Difference:", diff_result, "\n")
cat("Product:", prod_result, "\n")
cat("Division:", div_result, "\n\n")

# 3. Using loops
cat("For Loop Example:\n")
for (i in 1:5) {
  cat("Iteration:", i, "\n")
}

cat("\nWhile Loop Example:\n")
x <- 1
while (x <= 5) {
  cat("x =", x, "\n")
  x <- x + 1
}

# 4. User-defined function
add_numbers <- function(x, y) {
  result <- x + y
  return(result)
}

cat("\nFunction Output:\n")
cat("add_numbers(12, 8) =", add_numbers(12, 8), "\n")
