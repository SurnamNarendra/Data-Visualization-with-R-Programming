Lab 1: Introduction to R Environment and Basic Operations

Aim:

To get familiar with RStudio, variables, control structures, and simple user-defined functions.

Algorithm / Procedure:

  1. Open RStudio and explore console, script, and environment tabs.
  2. Use if(), for(), and while() loops.
  3. Create user-defined functions using function().

Input:

square <- function(x){return(x*x)}
square(5)

Output:

Returns the square of 5 as 25.
