T-Test in R

Aim

To compare the means of two groups using a t-test.

Algorithm / Procedure

  • Import the dataset.
  • Separate groups based on categorical variable.
  • Apply t.test() function.
  • Interpret p-value.

Input / Output (R Code)

# Sample dataset
data <- data.frame(
Gender = c("Male","Female","Male","Female","Male","Female"),
Marks = c(55,60,58,62,57,65)
)

# T-test
t_test_result <- t.test(Marks ~ Gender, data = data)
t_test_result

Result

The t-test compares the mean marks of male and female students. If p-value < 0.05, there is a significant difference between the two groups.

F-Test (ANOVA) in R

Aim

To test whether there is a significant difference among group means using ANOVA.

Algorithm / Procedure

  • Load dataset with numeric and categorical variables.
  • Use aov() function.
  • Display results using summary().
  • Visualize using boxplot.

Input / Output (R Code)

# Sample dataset
data <- data.frame(
Diet = factor(c("A","A","B","B","C","C")),
Weight = c(60,62,65,67,70,72)
)

# ANOVA
anova_result <- aov(Weight ~ Diet, data = data)
summary(anova_result)

# Boxplot
boxplot(Weight ~ Diet, data=data)

Result

ANOVA determines whether group means differ significantly. If p-value < 0.05, at least one group mean is different.

Chi-Square Test in R

Aim

To test association between two categorical variables using Chi-square test.

Algorithm / Procedure

  • Create contingency table.
  • Apply chisq.test().
  • Interpret p-value.

Input / Output (R Code)

# Sample data
Gender <- c("Male","Male","Female","Female","Male","Female")
Result <- c("Pass","Fail","Pass","Pass","Fail","Pass")

# Contingency table
table_data <- table(Gender, Result)

# Chi-square test
chisq_result <- chisq.test(table_data)
chisq_result

Result

The Chi-square test checks association between gender and result. If p-value < 0.05, the variables are significantly associated.
