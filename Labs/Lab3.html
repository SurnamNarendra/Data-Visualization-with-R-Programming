Lab 3: Probability Distributions

Frequency Distribution and Probability Visualization Using R Built-in Datasets

Aim

To generate and visualize random data from different statistical distributions (Binomial, Poisson, Normal, Uniform), compute frequency distributions, and understand the probability and density characteristics using R built-in datasets.

Theorey

Statistical distributions describe how values of a variable are spread or how often they occur. Random data can be generated in R to simulate these distributions. Density functions describe the likelihood of different outcomes, and probability functions give the expected frequency of events.

1. Binomial Distribution

The Binomial distribution models the number of successes in a fixed number of independent Bernoulli trials with the same probability of success. Random data can be generated using rbinom(), and probability density can be visualized using dbinom(). The histogram shows the frequency of each outcome.

2. Poisson Distribution

The Poisson distribution describes the number of events occurring in a fixed interval of time or space, assuming the events occur independently at a constant rate. Random data is generated with rpois(), and dpois() provides the probability mass function. It is useful for modeling counts of rare events.

3. Normal Distribution

The Normal distribution is a continuous distribution that is symmetric around its mean. Random data can be generated using rnorm(). The density function dnorm() and histogram with density overlay help visualize the bell-shaped distribution, showing how values cluster around the mean.

4. Uniform Distribution

The Uniform distribution represents equally likely outcomes within a specific interval. Random data can be generated with runif(), and dunif() gives the probability density. The histogram should be approximately flat, indicating that each value within the range is equally likely.

Algorithm

  1. Load a built-in dataset in R.
  2. Select a numeric variable.
  3. Create frequency distribution using cut() and table().
  4. Plot histogram and density curve.
  5. Generate random data from Binomial, Poisson, Normal, and Uniform distributions.
  6. Visualize probability or density functions using dbinom(), dpois(), dnorm(), dunif().

1. Binomial Distribution using quakes Dataset

The earthquakes dataset contains earthquake magnitudes. We convert magnitudes into a binary outcome: Success = magnitude > 5, Failure = otherwise. Random data and probabilities are visualized. 

# Load built-in dataset
data("quakes")

# Convert magnitudes to Binomial outcomes
success <- ifelse(quakes$mag > 5, 1, 0)

# Frequency table
table(success)

# Binomial probability plot
x <- 0:1
plot(x, dbinom(x, size=1, prob=mean(success)),
     type="h", col="blue", lwd=3,
     main="Binomial Distribution from Earthquake Magnitudes",
     xlab="Outcome (0 = Low, 1 = High)",
     ylab="Probability")

2. Poisson Distribution using airquality Dataset

High ozone days per month (Ozone > 80) behave like a Poisson process. Random data and Poisson probability mass function are visualized to understand the distribution of rare events. 

data("airquality")

# Count high-ozone days per month
high_ozone <- table(airquality$Month[airquality$Ozone > 80])
high_ozone

# Estimate lambda
lambda <- mean(high_ozone)

# Poisson probability bars
x <- 0:max(high_ozone)
plot(x, dpois(x, lambda),
     type="h", col="darkgreen", lwd=3,
     main="Poisson Distribution (High Ozone Days per Month)",
     xlab="High Ozone Days", ylab="Probability")

3. Normal Distribution using iris Dataset

The Petal Length in the iris dataset closely follows a normal distribution. Histograms with density curves and the theoretical normal curve are plotted to visualize data distribution. 

data("iris")

# Histogram + Density
hist(iris$Petal.Length, probability = TRUE,
     col="lightblue",
     main="Normal Distribution Example (Iris Petal Length)",
     xlab="Petal Length")

lines(density(iris$Petal.Length), col="red", lwd=2)

# Superimpose normal curve
x <- seq(min(iris$Petal.Length), max(iris$Petal.Length), 0.1)
curve(dnorm(x, mean=mean(iris$Petal.Length),
               sd=sd(iris$Petal.Length)),
      add=TRUE, col="blue", lwd=2)

4. Uniform Distribution using faithful Dataset

We take the range of the waiting time variable and generate uniform data within that range. Histogram and density function demonstrate equally likely outcomes within the interval. 

data("faithful")

min_w <- min(faithful$waiting)
max_w <- max(faithful$waiting)

# Generate uniform sample
u <- runif(200, min=min_w, max=max_w)

hist(u, probability=TRUE,
     col="khaki",
     main="Uniform Distribution (Based on Faithful Waiting Range)",
     xlab="Uniform Values")

curve(dunif(x, min_w, max_w),
      add=TRUE, col="purple", lwd=3)

Conclusion

This practical demonstrated the generation and visualization of random data from classical statistical distributions.

  • Binomial distribution models binary outcomes and its probability function shows the likelihood of success or failure.
  • Poisson distribution models counts of rare events, visualized using probability mass function.
  • Normal distribution models continuous variables with bell-shaped density curves.
  • Uniform distribution models equally likely outcomes within an interval.
By combining R built-in datasets with random data and probability functions, we gain a clear understanding of frequency, probability, and density concepts.
