Lab 9: Data Visualization Using R

Practical Steps for Students

  1. Load your assigned dataset:
    data(dataset_name)
    Example: data(mtcars); df <- mtcars
  2. Understand the data (EDA):
    head(df), str(df), summary(df)
    Write number of variables, types (numeric/factor), and meaning of data in your record.
  3. Univariate Visualization (at least 1):
    Example histogram/bar plot: 
    library(ggplot2)
ggplot(df, aes(x = df[,1])) +
    geom_histogram(bins = 10) +
    labs(title = "Distribution of Variable 1", x = "Variable", y = "Frequency")
    Explain what the distribution tells you about the data.
  4. Bivariate Visualization (at least 1):
    Example scatter plot: 
    ggplot(df, aes(x = df[,1], y = df[,2])) +
    geom_point() +
    labs(title = "Relationship between Variable 1 and Variable 2", x = "Variable 1", y = "Variable 2")
    Interpret the relationship between the variables.
  5. Categorical / Group Comparison (if applicable):
    Example boxplot: 
    ggplot(df, aes(x = factor(df[,3]), y = df[,1])) +
    geom_boxplot() +
    labs(title = "Comparison Across Categories", x = "Category", y = "Value")
    Explain insights for different groups.
  6. Decision-Oriented Visualization (mandatory):
    Example with trend line: 
    ggplot(df, aes(x = df[,1], y = df[,2])) +
    geom_point() +
    geom_smooth(method = "lm") +
    labs(title = "Decision-Making Visualization")
    Write a clear decision or recommendation based on this visualization.
  7. Result & Conclusion:
    • Result: Meaningful visualizations were created using R to analyze your dataset.
    • Conclusion: Visualization helped transform raw data into actionable insights for decision-making.
  8. Minimum Requirements:
    - Load dataset
    - Perform EDA
    - Create at least 3 visualizations
    - Provide decision insight for each plot
Note: Use only the dataset assigned to your roll number. Dataset change is not permitted.
