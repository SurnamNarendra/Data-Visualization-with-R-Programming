Lab 6: Regression Analysis Using R

Frequency Distribution and Probability Visualization Using R Built-in Datasets

Aim

To fit and analyze simple and multiple linear regression models, interpret coefficients, predict values, and assess model fit using R programming.

Procedure

  1. Load a dataset and inspect its structure.
  2. Fit a simple linear regression model using lm().
  3. Fit a multiple linear regression model using lm().
  4. Interpret regression coefficients, R-squared, and p-values.
  5. Predict new values using the fitted model.
  6. Visualize regression line with scatter plots.

Algorithm

  1. Start RStudio and set working directory.
  2. Load the dataset using read.csv() or built-in datasets.
  3. Inspect dataset structure using str() and summary().
  4. Fit simple linear regression: lm(Y ~ X).
  5. Fit multiple regression: lm(Y ~ X1 + X2 + ...).
  6. Use summary(model) to examine coefficients and R-squared.
  7. Predict new values using predict(model, newdata).
  8. Visualize data and regression line using plot() and abline().

Source Code

# Load dataset
data <- read.csv("your_dataset.csv")

# Inspect dataset
str(data)
summary(data)

# Simple Linear Regression
model1 <- lm(Y ~ X, data=data)
summary(model1)

# Multiple Linear Regression
model2 <- lm(Y ~ X1 + X2, data=data)
summary(model2)

# Predict new values
new_data <- data.frame(X=10, X1=5, X2=3)
predict(model2, newdata=new_data)

# Scatter plot with regression line
plot(data$X, data$Y, main="Scatter Plot with Regression Line", xlab="X", ylab="Y")
abline(model1, col="red")

Interpretation

  • Intercept (β0): Expected value of Y when all Xs are 0.
  • Slope (βi): Change in Y for a unit change in Xi, holding other variables constant.
  • R-squared: Proportion of variation in Y explained by Xs.
  • p-values: Test significance of coefficients; p < 0.05 indicates significant predictor.
