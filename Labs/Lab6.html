Correlation and Regression Analysis

Aim

To compute correlation and fit simple linear regression using R.

Algorithm / Procedure

  • Use cor() for correlation and lm() for regression.
  • Plot regression line with ggplot2.

Input / Output

Input:
> model <- lm(y~x, data=mydata)
> summary(model)
Output:
Regression coefficients

Result

Performed correlation and regression analysis on sample dataset.
