Lab 3: Probability Distributions

Frequency Distribution and Probability Visualization Using R Built-in Datasets

Aim

To create basic data visualizations such as bar plots, histograms, and pie charts using the ggplot2 package in R, and to customize titles, axes, and colors using the grammar of graphics.

Software Requirements

  • R (version 4.0 or above)
  • RStudio
  • ggplot2 package

Procedure

  1. Open RStudio.
  2. Install and load the ggplot2 package.
  3. Create or load a sample dataset.
  4. Use ggplot() to initialize the plot.
  5. Add appropriate geometry layers such as geom_bar(), geom_histogram(), or geom_col().
  6. Customize titles, axes labels, and colors.
  7. Execute the code and observe the output plots.

Input

1. Bar Plot

library(ggplot2)

data <- data.frame(
  Category = c("A", "B", "C", "D"),
  Values = c(12, 19, 7, 15)
)

ggplot(data, aes(x = Category, y = Values, fill = Category)) +
  geom_bar(stat = "identity") +
  labs(title = "Bar Plot Example",
       x = "Category",
       y = "Values") +
  theme_minimal()

2. Histogram

ggplot(mtcars, aes(x = mpg)) +
  geom_histogram(binwidth = 5, fill = "steelblue", color = "black") +
  labs(title = "Histogram of Mileage",
       x = "Miles Per Gallon",
       y = "Frequency") +
  theme_minimal()

3. Pie Chart

pie_data <- data.frame(
  Type = c("Apple", "Banana", "Orange"),
  Count = c(10, 15, 20)
)

ggplot(pie_data, aes(x = "", y = Count, fill = Type)) +
  geom_col(width = 1) +
  coord_polar(theta = "y") +
  labs(title = "Pie Chart Example") +
  theme_void()

Output

  • A bar plot displaying values for different categories with customized colors and labels.
  • A histogram showing the distribution of mileage values from the dataset.
  • A pie chart representing proportions of different fruit types.

Each plot clearly represents the data with appropriate titles, axes labels, and visual styling using the ggplot2 grammar.

Result

Thus, basic visualizations such as bar plots, histograms, and pie charts were successfully created and customized using the ggplot2 package in R.
