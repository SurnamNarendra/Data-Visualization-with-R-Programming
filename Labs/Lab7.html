Data Visualization using ggplot2

Aim

To create and customize data visualizations using ggplot2.

Algorithm / Procedure

  • Use ggplot(), geom_point(), geom_bar(), geom_histogram().
  • Customize labels, colors, and themes.

Input / Output

Input:
> ggplot(data, aes(x=Species, y=Length)) + geom_boxplot()

Result

Created effective and interpretable visualizations using ggplot2.
