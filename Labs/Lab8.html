Algorithm

  1. Download the assigned FASTA file based on roll number.
  2. Load the FASTA file into R using the seqinr package.
  3. Compute nucleotide frequencies (A, T, G, C).
  4. Calculate GC content (univariate analysis).
  5. Analyze relationships between nucleotide counts (bivariate analysis).
  6. Interpret biological significance of the results.

R Code (seqinr)

install.packages("seqinr")
library(seqinr)

# Read FASTA file
dna <- read.fasta("gene_RXX.fasta")

# Sequence length
length(dna[[1]])

# Univariate analysis
nuc_count <- count(dna[[1]], wordsize = 1)
gc_content <- GC(dna[[1]])

# Bivariate analysis
at <- nuc_count["A"] + nuc_count["T"]
gc <- nuc_count["G"] + nuc_count["C"]

# Simple plot
plot(c(at, gc),
     names = c("AT content", "GC content"),
     main = "AT vs GC Composition")

Input

A FASTA file containing a single DNA gene sequence of length 1000 bp.

Expected Outcome

Each student will obtain different nucleotide distributions and GC content values, leading to unique univariate and bivariate exploratory analysis results.

Conclusion

This experiment demonstrates how exploratory data analysis techniques can be applied to biological sequence data using R. The use of unique gene sequences ensures individual analysis and promotes understanding of nucleotide composition and sequence variability.
