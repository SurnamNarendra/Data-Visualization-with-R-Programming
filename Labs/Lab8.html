Lab 8: Exploratory Data Analysis of Gene Sequences

Aim

To perform Exploratory Data Analysis (EDA) on DNA gene sequences using the seqinr package in R and analyze univariate and bivariate characteristics.

Input

The input consists of a DNA gene sequence in FASTA format (1000 bp) and the following step-wise R implementation using the seqinr package.

Step 1: Install Required Package


# Install seqinr package (run once)
install.packages("seqinr")

Step 2: Load Required Library


library(seqinr)

Step 4: Read FASTA Gene Sequence


gene <- read.fasta("gene_R05.fasta")
dna_seq <- gene[[1]]

Step 5: Basic Sequence Information


# Length of DNA sequence
length(dna_seq)

Step 6: Univariate EDA – Nucleotide Frequency


base_freq <- table(dna_seq)
base_freq

Step 7: Univariate Plot – Base Composition


barplot(base_freq,
        main = "Nucleotide Frequency Distribution",
        xlab = "Nucleotide",
        ylab = "Count",
        col = "lightblue")

Step 8: GC and AT Content Analysis


gc_content <- GC(dna_seq)
at_content <- 1 - gc_content

gc_content
at_content

Step 9: Bivariate EDA – Purine vs Pyrimidine


purine <- base_freq["A"] + base_freq["G"]
pyrimidine <- base_freq["C"] + base_freq["T"]

barplot(c(purine, pyrimidine),
        names.arg = c("Purine", "Pyrimidine"),
        main = "Purine vs Pyrimidine Distribution",
        ylab = "Count",
        col = "lightgreen")

Step 11: Advanced EDA – Dinucleotide Frequency


dinucleotideFrequency(dna_seq)

Step 12: Tri-nucleotide Frequency Analysis


# Tri-nucleotide frequency
tri_freq <- wordFrequency(dna_seq, wordsize = 3)
tri_freq

Output

  • Gene sequence length confirmation (1000 bp)
  • Nucleotide frequency and proportions
  • GC and AT content values
  • Univariate bar plots
  • Bivariate comparison plots
  • Different results for each student
