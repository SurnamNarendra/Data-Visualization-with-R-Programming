Lab 3: Probability Distributions

Frequency Distribution and Probability Visualization Using R Built-in Datasets

Aim

To create basic data visualizations such as bar plots, histograms, and pie charts using the ggplot2 package in R, and to customize titles, axes, and colors using the grammar of graphics.

Software Requirements

  • R (version 4.0 or above)
  • RStudio
  • ggplot2 package

Procedure

  1. Open RStudio.
  2. Install and load the ggplot2 package.
  3. Create or load a sample dataset.
  4. Use ggplot() to initialize the plot.
  5. Add appropriate geometry layers such as geom_bar(), geom_histogram(), or geom_col().
  6. Customize titles, axes labels, and colors.
  7. Execute the code and observe the output plots.

Input

Step 1: Load Library & Set Seed

library(ggplot2)

# Replace 101 with your Roll Number
set.seed(101)

Step 2: Bar Plot (Random Data)

bar_data <- data.frame(
  Category = paste("Category", 1:5),
  Values = sample(10:100, 5)
)

ggplot(bar_data, aes(x = Category, y = Values, fill = Category)) +
  geom_bar(stat = "identity") +
  labs(
    title = "Bar Plot with Random Values",
    x = "Categories",
    y = "Values"
  ) +
  theme_minimal()

Step 3: Histogram (Random Distribution)

hist_data <- data.frame(
  Marks = rnorm(100, mean = sample(60:80, 1), sd = sample(5:15, 1))
)

ggplot(hist_data, aes(x = Marks)) +
  geom_histogram(binwidth = 5, fill = "darkorange", color = "black") +
  labs(
    title = "Histogram of Random Marks",
    x = "Marks",
    y = "Frequency"
  ) +
  theme_minimal()

Step 4: Pie Chart (Random Proportions)

pie_data <- data.frame(
  Section = paste("Section", LETTERS[1:4]),
  Count = sample(10:50, 4)
)

ggplot(pie_data, aes(x = "", y = Count, fill = Section)) +
  geom_col(width = 1) +
  coord_polar(theta = "y") +
  labs(title = "Pie Chart with Random Data") +
  theme_void()

Step 5: Boxplot (Random Data Distribution)

# Create random data for boxplot
set.seed(sample(1:1000, 1))

box_data <- data.frame(
  Category = rep(c("Group A", "Group B", "Group C"), each = 20),
  Values = c(
    rnorm(20, mean = sample(40:60, 1), sd = sample(5:10, 1)),
    rnorm(20, mean = sample(60:80, 1), sd = sample(5:10, 1)),
    rnorm(20, mean = sample(80:100, 1), sd = sample(5:10, 1))
  )
)

# Boxplot using ggplot2
ggplot(box_data, aes(x = Category, y = Values, fill = Category)) +
  geom_boxplot() +
  labs(
    title = "Boxplot of Randomly Generated Data",
    x = "Category",
    y = "Values"
  ) +
  theme_minimal()

Output

  • A bar plot displaying values for different categories with customized colors and labels.
  • A histogram showing the distribution of mileage values from the dataset.
  • A pie chart representing proportions of different fruit types.
  • A boxplot to detect outlier

Each plot clearly represents the data with appropriate titles, axes labels, and visual styling using the ggplot2 grammar.
