Lab 2: Heart Rate Analysis of 5 Patients

Perform descriptive statistics on heart rate data and identify the most consistent patient.

Aim

To perform descriptive statistical analysis of heart rate data from 5 patients (20 measurements each) in R, including mean, median, mode, range, variance, standard deviation, coefficient of variation, skewness, kurtosis, and outlier detection, and determine the most consistent patient.

Algorithm

  1. Collect or input heart rate data of 20 samples for 5 patients.
  2. Calculate mean, median, and mode for each patient.
  3. Compute range, variance, and standard deviation.
  4. Compute coefficient of variation (CV) to assess consistency.
  5. Compute skewness and kurtosis for data distribution analysis.
  6. Detect any outliers using descriptive methods or boxplot visualization.
  7. Compare CV values to identify the most consistent patient.
  8. Visualize distributions using boxplots.

Source Code

# Lab 2: Heart Rate Analysis of 5 Patients

# Heart rate data (20 measurements each)
patient1 <- c(72,75,74,71,73,72,76,74,73,72,74,75,73,72,71,74,73,75,72,73)
patient2 <- c(80,82,78,81,79,80,81,82,79,80,78,81,80,79,82,80,81,79,80,82)
patient3 <- c(65,67,66,65,66,65,67,66,65,66,67,66,65,66,65,66,65,67,66,65)
patient4 <- c(90,88,91,89,90,91,89,90,88,90,89,91,90,89,90,91,90,89,90,88)
patient5 <- c(78,77,79,78,77,78,79,78,77,78,79,77,78,77,79,78,77,78,79,78)

patients <- list(P1=patient1, P2=patient2, P3=patient3, P4=patient4, P5=patient5)

# Install moments package if not installed
if(!require(moments)) install.packages("moments")
library(moments)

# Function to calculate descriptive stats
descriptive_stats <- function(data){
  mean_val <- mean(data)
  median_val <- median(data)
  mode_val <- as.numeric(names(sort(table(data), decreasing=TRUE)[1]))
  range_val <- max(data)-min(data)
  variance_val <- var(data)
  sd_val <- sd(data)
  cv <- (sd_val/mean_val)*100
  skew <- skewness(data)
  kurt <- kurtosis(data)
  list(Mean=mean_val, Median=median_val, Mode=mode_val,
       Range=range_val, Variance=variance_val, SD=sd_val, CV=cv,
       Skewness=skew, Kurtosis=kurt)
}

# Calculate stats for each patient
stats <- lapply(patients, descriptive_stats)

# Print descriptive stats
for(p in names(stats)){
  cat("\\nDescriptive Statistics for", p, ":\\n")
  print(stats[[p]])
}

# Identify most consistent patient
cv_values <- sapply(stats, function(x) x$CV)
most_consistent <- names(cv_values)[which.min(cv_values)]
cat("\\nMost consistent patient (lowest CV):", most_consistent, "with CV =", round(min(cv_values),2), "%\\n")

# Boxplot visualization
boxplot(patient1, patient2, patient3, patient4, patient5,
        names=c("P1","P2","P3","P4","P5"),
        col="lightgreen",
        main="Heart Rate Distribution of 5 Patients",
        ylab="Heart Rate (bpm)")

Conclusion

In this lab, we analyzed heart rate measurements of 5 patients using descriptive statistics in R. We calculated measures of central tendency, dispersion, coefficient of variation, skewness, and kurtosis. Boxplot visualization helped observe variability and detect outliers. The patient with the lowest CV was identified as the most consistent, demonstrating the importance of variability analysis in biostatistical studies.
