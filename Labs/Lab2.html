Data Types and Descriptive Statistics

Aim

To identify variable types and compute basic descriptive statistics using R.

Algorithm / Procedure

  • Create vectors for qualitative and quantitative data.
  • Use functions mean(), median(), mode(), sd().

Input / Output

Input:
> data <- c(5,10,15,20)
> mean(data)
Output:
[1] 12.5

Result

Calculated and interpreted descriptive measures in R.
