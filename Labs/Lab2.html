Lab 2: Heart Rate Analysis of 5 Patients

Perform descriptive statistics on heart rate data and identify the most consistent patient.

Aim

To perform descriptive statistical analysis of heart rate data from 5 patients (20 measurements each) in R, including mean, median, mode, range, variance, standard deviation, coefficient of variation, skewness, kurtosis, and outlier detection using quartiles and boxplots.

Algorithm

  1. Generate heart rate data for 20 samples of 5 patients.
  2. Convert the data into long format for analysis.
  3. Compute descriptive statistics (mean, median, SD, range, variance, etc.).
  4. Compute quartiles (Q1, Q3), IQR, and detect outliers using boxplot fences.
  5. Create line chart to show heart rate trend for each patient.
  6. Create boxplot to study distribution and variability.
  7. Create density plot to analyze distribution shape.
  8. Identify the most consistent patient using coefficient of variation.

Source Code

# Lab 2: Heart Rate Analysis of 5 Patients

library(dplyr)
library(ggplot2)
library(moments)

# Simulated patient data
p1 <- sample(60:100, 20, replace = TRUE)
p2 <- sample(60:100, 20, replace = TRUE)
p3 <- sample(60:100, 20, replace = TRUE)
p4 <- sample(60:100, 20, replace = TRUE)
p5 <- sample(60:100, 20, replace = TRUE)

patients <- data.frame(p1, p2, p3, p4, p5);patients

# Convert to long format
df <- do.call(rbind, lapply(names(patients), function(p){
  data.frame(Patient = p, HR = patients[[p]])
}))

# Descriptive statistics + Q1 Q3 Outliers
simple_stats <- df %>%
  group_by(Patient) %>%
  summarise(
    Mean = mean(HR),
    Median = median(HR),
    SD = sd(HR),
    Range = max(HR) - min(HR),
    Variariance = var(HR),
    CV = (sd(HR) / mean(HR)) * 100,
    Skewness = skewness(HR),
    Kurtosis = kurtosis(HR),

    Q1 = quantile(HR, 0.25),
    Q3 = quantile(HR, 0.75),
    IQR = IQR(HR),

    Lower_Fence = Q1 - 1.5 * IQR,
    Upper_Fence = Q3 + 1.5 * IQR,

    Outliers = paste(HR[HR < Lower_Fence | HR > Upper_Fence], collapse = ", ")
  )

print(simple_stats, width = Inf)

# Line chart
df$Index <- ave(df$HR, df$Patient, FUN = seq_along)

ggplot(df, aes(x = Index, y = HR, color = Patient)) +
  geom_line(linewidth = 1) +
  geom_point(size = 1.2) +
  theme_minimal(base_size = 14) +
  labs(title = "Heart Rate Trend for All Patients",
       x = "Observation Index", y = "Heart Rate (bpm)") +
  scale_color_brewer(palette = "Dark2")

# Boxplot
ggplot(df, aes(x = Patient, y = HR, fill = Patient)) +
  geom_boxplot(alpha = 0.8, outlier.color = "red", outlier.size = 3) +
  theme_minimal(base_size = 14) +
  labs(title = "Heart Rate Distribution by Patient",
       y = "Heart Rate (bpm)") +
  scale_fill_brewer(palette = "Set2")

# Density plot
ggplot(df, aes(x = HR, color = Patient, fill = Patient)) +
  geom_density(alpha = 0.3) +
  theme_minimal(base_size = 14) +
  labs(title = "Density Plot of Heart Rates",
       x = "Heart Rate (bpm)", y = "Density") +
  scale_fill_brewer(palette = "Set1") +
  scale_color_brewer(palette = "Set1")

Conclusion

In this lab, heart rate data of 5 patients was analyzed using descriptive statistics, quartiles, and outlier detection. Line charts, boxplots, and density plots provided visual insights into consistency and variability. Coefficient of Variation (CV) helps identify the most stable patient, while IQR and fences indicate outliers in the dataset.
