Lecture 15 — Regression

📈 Regression — Definition, Formula, Types & Examples

What is Regression?

Regression analysis predicts the relationship between a dependent variable (Y) and one or more independent variables (X).

Simple Linear Regression Formula:

$$ Y = \beta_0 + \beta_1 X + \epsilon $$
Multiple Linear Regression Formula:

$$ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_n X_n + \epsilon $$

Types of Regression (With Examples)

1️⃣ Simple Linear Regression
Predict Y using a single X.

Example: Predict students' marks (Y) using study hours (X).

2️⃣ Multiple Linear Regression
Predict Y using multiple X variables.

Example: Predict house price (Y) using area, bedrooms, and location (X1, X2, X3).

3️⃣ Polynomial Regression
Fits non-linear relationships by using powers of X.

Example: Predict growth curve of plants over time.

4️⃣ Logistic Regression
Predict binary outcomes.

Example: Predict if a student passes (1) or fails (0) based on study hours.
