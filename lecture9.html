Lecture 15 — Regression

📈 Regression — Definition, Formula, Types & Examples

What is Regression?

Regression analysis predicts the relationship between a dependent variable (Y) and one or more independent variables (X).

Simple Linear Regression Formula:

$$ Y = \beta_0 + \beta_1 X + \epsilon $$
Multiple Linear Regression Formula:

$$ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \dots + \beta_n X_n + \epsilon $$

Types of Regression (With Examples)

1️⃣ Simple Linear Regression
Predict Y using a single X.

Example: Predict students' marks (Y) using study hours (X).

2️⃣ Multiple Linear Regression
Predict Y using multiple X variables.

Example: Predict house price (Y) using area, bedrooms, and location (X1, X2, X3).

3️⃣ Polynomial Regression
Fits non-linear relationships by using powers of X.

Example: Predict growth curve of plants over time.

4️⃣ Logistic Regression
Predict binary outcomes.

Example: Predict if a student passes (1) or fails (0) based on study hours.

Example: Linear Regression in R using lm()

We use the lm() function in R to fit linear regression models.

Example 1: Simple Linear Regression
Predict marks using study_hours.

# Sample data
study_hours <- c(2, 3, 5, 7, 9)
marks <- c(50, 55, 65, 70, 80)

# Fit model
model <- lm(marks ~ study_hours)
# View summary
summary(model)

Example 2: Multiple Linear Regression
Predict house_price using area and bedrooms.

# Sample data
area <- c(1000, 1500, 2000, 2500, 3000)
bedrooms <- c(2, 3, 3, 4, 5)
price <- c(200, 250, 300, 350, 400)

# Fit model
model <- lm(price ~ area + bedrooms)
summary(model)

Top 10 Real-World Applications of Regression

1. Predicting House Prices

Using factors like area, number of bedrooms, and location to estimate property prices.

2. Stock Market Analysis

Predicting stock prices based on historical trends, market indices, and economic indicators.

3. Sales Forecasting

Estimating future sales based on advertising spend, seasonality, and market trends.

4. Medical Risk Assessment

Predicting patient outcomes like disease risk using age, lifestyle, and test results.

5. Marketing Analytics

Analyzing the effect of campaigns on customer engagement or conversion rates.

6. Weather Forecasting

Predicting temperature, rainfall, or humidity using historical weather data.

7. Manufacturing & Quality Control

Estimating product quality based on process parameters and raw material characteristics.

8. Traffic Flow Analysis

Predicting traffic volume based on time of day, weather, and road conditions.

9. Energy Consumption Prediction

Estimating electricity usage based on temperature, appliance usage, and occupancy.

10. Sports Analytics

Predicting players’ performance metrics or team outcomes based on past performance data.
