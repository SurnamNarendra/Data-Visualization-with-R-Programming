Lecture 7 — Introduction to R

This lecture introduces R, a powerful programming language for statistical computing and data analysis. R is widely used in biological, clinical, and research applications for data manipulation, visualization, and modeling.

1. R Environment

R can be used through:

  • R Console: Directly type commands and execute.
  • RStudio IDE: Provides script editor, console, plots, and workspace management.
  • R Scripts: Store and execute multiple commands from a file.
Example:
  • Opening RStudio and running 2 + 3 in the console returns 5.

2. Basic Operations

  • Addition: 5 + 7 → 12
  • Subtraction: 10 - 4 → 6
  • Multiplication: 3 * 4 → 12
  • Division: 20 / 5 → 4
  • Exponentiation: 2^3 → 8

3. Variables and Assignment

Assign values using <- or =.

glucose <- c(90, 110, 120, 100)
weight = c(60, 70, 80, 65)
Example: Store fasting glucose levels for 4 patients in glucose vector and weights in weight vector.

4. Data Types

  • Numeric: x <- 5
  • Character: name <- "Patient1"
  • Logical: status <- TRUE
  • Vector: v <- c(1,2,3)
  • Matrix: m <- matrix(1:6, nrow=2, ncol=3)
  • Data Frame: df <- data.frame(glucose, weight)

5. Basic Functions

  • Mean: mean(glucose)
  • Median: median(glucose)
  • Standard Deviation: sd(glucose)
  • Summary: summary(df)
  • Length: length(weight)
Example: Calculate mean fasting glucose, standard deviation, and check data summary for patient dataset.

6. Data Indexing and Subsetting

  • Access vector element: glucose[2] → second value
  • Access multiple: weight[c(1,3)]
  • Access data frame column: df$glucose
  • Subset rows: df[df$weight > 65, ]

7. Basic Plotting

Visualizing data using simple plots.

plot(glucose, weight, xlab="Glucose (mg/dL)", ylab="Weight (kg)", main="Glucose vs Weight")
hist(glucose, main="Histogram of Glucose", xlab="Glucose Levels", col="lightblue")
Example: Scatter plot of fasting glucose vs weight, histogram of glucose distribution for a patient group.

8. Summary

  • R is a versatile tool for data analysis, visualization, and statistical modeling.
  • Basic operations, variables, vectors, and data frames are fundamental for handling datasets.
  • Built-in functions and plotting tools allow rapid analysis of biological and medical data.
  • Understanding R syntax and workflow is essential for practical data-driven research.
