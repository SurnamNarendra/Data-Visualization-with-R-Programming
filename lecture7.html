Lecture 7 — Introduction to R (Expanded Version)

This expanded lecture provides a deeper introduction to R, including the environment, data structures, indexing, functions, and plotting. Additional examples are included to help strengthen understanding.

1. R Environment

You can work with R in various environments:

  • R Console: Good for quick calculations.
  • RStudio IDE: Includes panels for console, script editing, plots, and environment management.
  • R Markdown: Create reports mixing R code and text.
  • R Scripts: Save all commands for reproducibility.
Example:
  • Type getwd() in the console to check your working directory.
  • Use setwd("C:/folder") to change your working directory.

2. Basic Operations

R can perform all arithmetic operations:

  • 5 + 7 → 12
  • 10 - 4 → 6
  • 3 * 4 → 12
  • 20 / 5 → 4
  • 2^4 → 16
  • sqrt(49) → 7
Extra Example (Biomedical Context):

Convert weight from kg to pounds: 70 * 2.20462 → 154.3 lbs

3. Variables and Assignment

R allows assignment using <- or =.

glucose <- c(90, 110, 120, 100)
weight = c(60, 70, 80, 65)
bmi <- weight / ((1.65)^2) # simple BMI example
Example: Store heights of four patients: height <- c(1.6, 1.7, 1.65, 1.8)

4. Data Types

Understanding R data types is essential:

  • Numeric: x <- 3.14
  • Integer: y <- 10L
  • Character: name <- "R Studio"
  • Logical: flag <- TRUE
  • Vector: v <- c(1,2,3,4)
  • Matrix: matrix(1:9, nrow=3)
  • List: list(name="John", age=30, scores=c(70,80))
  • Data Frame: df <- data.frame(glucose, weight)
More Examples:
  • Create factor for blood groups: blood <- factor(c("A","B","O","AB","A"))
  • List storing mixed data: patient <- list(id=101, bp=c(120,80), diabetic=FALSE)

5. Basic Functions

  • mean(glucose)
  • median(glucose)
  • sd(glucose)
  • summary(df)
  • length(weight)
  • range(glucose)
  • var(weight)

Creating Your Own Function

bmi_calc <- function(weight, height){ weight / (height^2) }
Example: bmi_calc(70, 1.75) → 22.86

6. Data Indexing and Subsetting

  • glucose[1] → first value
  • glucose[2:4] → positions 2 to 4
  • weight[c(1,3)]
  • df$glucose
  • df[df$weight > 65, ]
  • df[df$glucose <= 100, ]
Practical Example:

Find patients with glucose above 110:

df[df$glucose > 110, ]

7. Basic Plotting

R provides simple yet powerful plotting functions.

plot(glucose, weight, xlab="Glucose (mg/dL)", ylab="Weight (kg)", main="Glucose vs Weight")

hist(glucose, main="Histogram of Glucose", xlab="Glucose Levels", col="lightblue")

boxplot(weight, main="Boxplot of Weight", ylab="Weight (kg)")
Additional Examples:
  • plot(df$glucose, type="l", main="Glucose Trend", col="blue")
  • barplot(table(blood), main="Blood Group Distribution")

8. Summary

  • R provides powerful tools for data analysis and visualization.
  • Data types such as vectors, matrices, lists, and data frames form the foundation.
  • Indexing and subsetting allow extraction of specific information.
  • Plots help visualize trends and distributions in biomedical data.
  • Learning R improves reproducibility and efficiency in research.
