Lecture 2 — Data Collection, Organization, and Presentation

This lecture focuses on how data is gathered, organized, and represented for meaningful interpretation. Proper data collection ensures accuracy and reliability, while systematic organization and presentation make patterns and relationships easier to identify.

1. Data Collection Methods

Data collection is the process of gathering information from different sources to answer research questions or test hypotheses. It can be primary (collected firsthand) or secondary (using existing sources).

  • Observation: Recording data through direct monitoring. Example: Observing the growth rate of bacterial colonies under different temperature conditions.
  • Survey or Questionnaire: Collecting responses from participants using structured forms. Example: Gathering information about daily calorie intake among adults.
  • Experimentation: Controlling variables to study cause-effect relationships. Example: Measuring enzyme activity at varying pH levels.
  • Existing Records: Using previously collected data or reports. Example: Using hospital records to analyze seasonal variations in blood sugar levels.

2. Types of Data

Data can be categorized based on its nature and measurement level.

  • Qualitative Data: Descriptive information, such as color, type, or category. Example: Blood groups (A, B, AB, O) of patients.
  • Quantitative Data: Numerical values that can be measured.
    • Discrete: Countable data (e.g., number of cells in a microscope field).
    • Continuous: Measurable data (e.g., weight of tissue samples in grams).

3. Data Organization

Once collected, data must be organized in a structured form to simplify analysis. Common methods include:

  • Tabulation: Presenting data in rows and columns. Example: Recording the average glucose levels of participants grouped by age.
  • Frequency Distribution: Showing how often each value or range occurs. Example: Number of students with cholesterol levels in intervals: 150–170, 171–190, 191–210, etc.

The relative frequency of a class can be calculated using:

Relative Frequency = (Class Frequency) / (Total Frequency)

4. Graphical Presentation of Data

Graphical tools help visualize patterns, comparisons, and distributions. Common forms include:

  • Bar Diagram: Represents categorical data using bars. Example: Comparing the average protein intake among different dietary groups.
  • Histogram: Used for continuous data divided into intervals. Example: Distribution of hemoglobin levels among 100 patients.
  • Pie Chart: Shows the percentage composition of categories. Example: Percentage of different blood types in a population.
  • Line Graph: Displays trends over time. Example: Monthly variation in average body temperature during a viral infection study.

5. Measures of Central Tendency

These are values that describe the center or typical value of a dataset.

  • Mean (Arithmetic Average):

    Mean = (Σx) / n

    Example: Average heart rate of 10 subjects measured in beats per minute.
  • Median: The middle value when data is arranged in order. Example: Median white blood cell count in a set of 9 samples.
  • Mode: The value that appears most frequently. Example: The most common blood pressure reading in a patient group.

6. Measures of Dispersion

Dispersion shows how much the data values differ from the central value.

  • Range: Difference between maximum and minimum values.

    Range = Maximum - Minimum

  • Variance (σ²):

    σ² = Σ(x - μ)² / n

  • Standard Deviation (σ):

    σ = √(Σ(x - μ)² / n)

Example: Measuring variation in fasting glucose levels among 20 participants.

7. Importance of Data Presentation

Effective presentation helps in drawing insights, making decisions, and communicating results clearly. Charts, graphs, and tables enable quick pattern recognition and improve understanding.

Example: Displaying the impact of nutrient intake on weight changes using a combined bar and line chart provides both numerical and visual insights.
