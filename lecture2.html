Lecture 2 — Measurement Scales

Nominal, Ordinal, Interval,Ratio.

In biostatistics, understanding measurement scales is fundamental before performing any data analysis. Each variable type determines which statistical techniques and visualizations are appropriate in R.

Nominal Scale

Nominal data classify observations into categories without any natural order. Each category is distinct and mutually exclusive.

Examples in Biostatistics:
  • 1️⃣ Blood group — A, B, AB, O
  • 2️⃣ Gender — Male, Female, Other
  • 3️⃣ Blood type — Positive / Negative (Rh factor)
  • 4️⃣ Type of microorganism — Bacteria, Virus, Fungi, Parasite
  • 5️⃣ Marital status — Single, Married, Divorced, Widowed
  • 6️⃣ Religion or ethnicity in demographic data
  • 7️⃣ Smoking status — Smoker, Non-smoker
  • 8️⃣ Type of diet — Vegetarian, Non-vegetarian, Vegan
  • 9️⃣ Type of hospital — Government, Private, Teaching
  • 🔟 Diagnostic test result — Positive, Negative

Why analyze nominal data?
To study frequency distributions, proportions, and associations between categorical variables (e.g., using Chi-square tests).

In R:

blood <- factor(c("A","B","O","A","AB","O"))
table(blood)
prop.table(table(blood))
barplot(table(blood), col="skyblue", main="Blood Group Distribution")

Ordinal Scale

Ordinal data have categories with a logical order or ranking, but the differences between ranks are not uniform.

Examples in Biostatistics:
  • 1️⃣ Pain intensity — Mild, Moderate, Severe
  • 2️⃣ Disease stage — Stage I, II, III, IV
  • 3️⃣ Likert scale — Strongly Disagree to Strongly Agree
  • 4️⃣ Socioeconomic class — Low, Middle, High
  • 5️⃣ BMI category — Underweight, Normal, Overweight, Obese
  • 6️⃣ Risk level — Low, Medium, High
  • 7️⃣ Tumor grade — G1, G2, G3
  • 8️⃣ Satisfaction level of patients — Poor, Fair, Good, Excellent
  • 9️⃣ Education level — Primary, Secondary, Graduate, Postgraduate
  • 🔟 Burn severity — First, Second, Third degree

Why analyze ordinal data?
To compare ordered responses (e.g., median, percentiles, nonparametric tests like Mann–Whitney U or Kruskal–Wallis). Visualized using bar plots or stacked charts.

In R:

pain <- factor(c("Mild","Moderate","Severe","Mild"), ordered=TRUE)
summary(pain)
barplot(table(pain), col="lightgreen", main="Pain Intensity Levels")

Interval Scale

Interval data are numerical with equal intervals between values but no true zero point. Differences are meaningful; ratios are not.

Examples in Biostatistics:
  • 1️⃣ Body temperature in °C or °F
  • 2️⃣ IQ score
  • 3️⃣ Psychological scale scores (e.g., depression score)
  • 4️⃣ pH values of biological samples
  • 5️⃣ Heart rate variability index (when rescaled)
  • 6️⃣ Enzyme activity measured on arbitrary scale
  • 7️⃣ Scale-based pain ratings converted numerically
  • 8️⃣ Blood oxygen saturation deviation from baseline
  • 9️⃣ ECG signal differences (after normalization)
  • 🔟 Gene expression Z-scores

Why analyze interval data?
You can calculate means, standard deviations, and use correlation or regression (as long as variables have consistent intervals). However, ratio comparisons (like “twice as much”) are not meaningful because there’s no absolute zero.

In R:

temp <- c(36.5, 37.0, 38.2, 36.8, 37.4)
mean(temp); sd(temp)
hist(temp, col="lightpink", main="Body Temperature (°C)")

Ratio Scale

Ratio data have all the properties of interval data and also a meaningful zero — allowing computation of ratios.

Examples in Biostatistics:
  • 1️⃣ Height (cm)
  • 2️⃣ Weight (kg)
  • 3️⃣ Blood pressure (mmHg)
  • 4️⃣ Heart rate (beats per minute)
  • 5️⃣ Serum cholesterol (mg/dL)
  • 6️⃣ Glucose concentration (mg/dL)
  • 7️⃣ White blood cell count (cells/µL)
  • 8️⃣ Duration of hospital stay (days)
  • 9️⃣ Age (years)
  • 🔟 Reaction time (seconds)

Why analyze ratio data?
These are true quantitative variables. You can compute all descriptive statistics (mean, variance, coefficient of variation) and perform correlation, regression, and ANOVA in R. Visualization can include histograms, scatter plots, boxplots, etc.

In R:

weight <- c(55,60,72,48,67,80)
height <- c(1.65,1.68,1.75,1.60,1.70,1.82)
bmi <- weight / (height^2)
summary(bmi)
plot(height, weight, col="purple", pch=19, main="Height vs Weight")
